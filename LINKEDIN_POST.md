# LinkedIn Post Draft

I built a VS Code extension for OpenFOAM case files to make everyday setup work a bit less tedious.

It adds syntax highlighting, hover help, smarter completions, and a visual inspector for dictionaries like `fvSchemes`, `fvSolution`, `controlDict`, `blockMeshDict`, and `snappyHexMeshDict`.

One part I especially like is the geometry preview inside the inspector. If a case references an STL or similar geometry file, you can open it directly in a 3D view, rotate it, pan around it, and inspect it without leaving VS Code.

The repo is here:
https://github.com/Arefhm94/openfoam-vscode-extension

If you work with OpenFOAM regularly, I’d be interested to hear what would make this more useful in real cases.
